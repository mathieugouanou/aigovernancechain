# GovBench

Does an AI model know **when** AI-governance rules apply and **where** they are written? GovBench asks multiple-choice questions generated from high-confidence obligations in the Obligation Atlas. See [STATS.md](STATS.md) for the current counts.

| Type | Example |
|---|---|
| `date` | "From which date does EU AI Act Art. 50(1) apply?" |
| `citation` | "Which provision contains this obligation?" |
| `status` | "As of 2026-11-04, is this obligation applicable, not yet applicable, proposed or voluntary?" |

## Run it

```bash
npx github:mathieugouanou/aigovernancechain bench --questions > questions.jsonl
# ask your model each question; write one line per answer: {"id": "...", "answer": "B"}
npx github:mathieugouanou/aigovernancechain bench --answers answers.jsonl
```

Answers may be a letter or the exact choice text. Prompt suggestion: "Answer with the letter only. If unsure, answer anyway."

## Limits (read before quoting a score)

- Tests recall of dated, cited facts, not legal reasoning, judgement or safety.
- Answers are only as good as the Atlas, which is `draft-unreviewed` as of 4 Nov 2026. Each question carries its `source_url`.
- Distractors are generated automatically. Some may be easy to rule out; `status` questions skew towards "applicable".
- The dataset is public, so models may have seen it. Report the dataset date with every score.
- A leaderboard with method details is planned for v1 (30 Nov 2026).
